# Two passing takes first

## Before recording

- Run the current build on the iPhone. Turn up speech volume and make a short audio recording check.
- Export the verified package to Files and AirDrop a backup to the Mac. Never delete the app before export.
- Use only the team's observed ENB room, landmarks and reviewed links. Do not film the practice guide as a real route.
- Check battery, permissions, readable text size and screen-recording audio. Avoid capturing bystanders or private rooms.

## Scene 1 — a real room

1. Film a volunteer standing in the public hallway, camera capture active, marking a usable stopping point and labeling the actual ENB door sign.
2. Save the world map, review directed connections, verify Step-free and publish.
3. Quit/relaunch while unplugged. Home → search the same signed room → choose named start → Step-free route preview.
4. Start directions. Capture a clearly visible Next step interaction and audible instruction. Show actual Tracking or the honest manual/recovery state; never imply automatic recognition if it did not happen.
5. If the verified route uses the elevator, show the intended floor and explicit confirmation after exiting. Resume automatic mode only after relocalization.
6. Show the room sign, Confirm arrival, and Done. Save this take before adding more routes.

## Scene 2 — clothing resource

1. Tap Ask with your voice and say “Where can I rent a suit?” Stop recording, correct the editable transcript if necessary, and tap Search.
2. Open Suit-A-Bull. Hold on its answer, **SVC 2060** and official **USF Career Services** link.
3. Open walking directions. Verify Apple Maps shows the Tampa **Student Services Building**, not the general USF campus pin. End the scene there; indoor SVC directions are not published.
4. Check recorded audio and text legibility. If Debug diagnostics say fallback, describe the take as local directory matching, not live AI. A successful health response alone does not establish live AI.

## Device verification before claiming completion

- Scan → mark → label → save → publish → unplug/relaunch → search → guide on the real route.
- Relocalize from the saved start; lose tracking intentionally in a safe stationary position; confirm manual controls remain usable.
- Test floor transfer with separate maps, stairs/closed/unverified exclusion, Repeat/Next/arrival, background/resume and End route.
- Deny camera/speech access and confirm typed/manual alternatives. Re-enable in Settings.
- Export/import on a second installation, check duplicate rejection and immediate search visibility. Accept/reject/link a suggestion, then publish.
- Check proxy health from the physical iPhone and separately confirm a `Live AI` diagnostic. Turn off the proxy and verify fallback.
- Check Maps pin, VoiceOver focus order, larger text, dark appearance and readable controls over the camera area. A simulator take cannot verify ENB navigation.
